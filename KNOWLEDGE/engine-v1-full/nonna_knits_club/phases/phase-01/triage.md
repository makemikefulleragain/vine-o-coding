# Phase 1 Triage — What to Build

**Date:** 2026-02-15

---

## The Phase 1 Goal (from PHASE_QUEUE.md)

"A simple place to post about the things they made and ask questions and search lists of local groups, on-line or in-person or sources to find patterns and people"

## Triage Decision

The goal is still right. Research confirms all three needs are real:

1. **Community Board (post + ask)** — Crafters share FOs, WIPs, and questions across fragmented platforms. A simple board consolidates this.
2. **Group Finder (search local groups)** — Finding in-person groups is a top pain point. Fragmented across Meetup, Facebook, yarn shop boards, guild directories.
3. **Resource Links (patterns + people)** — Pattern discovery is spread across Ravelry, YouTube, blogs. Curated links add real value.

## What NOT to build in Phase 1

- User accounts / authentication (localStorage is enough)
- Image upload (link to images hosted elsewhere — Instagram, Imgur)
- Real-time chat
- Pattern database (link to Ravelry instead)
- Payment / marketplace (that's Phase 2)

## Does something already exist we should integrate with?

**Yes.** We should link to, not replace:
- Ravelry for patterns
- Meetup for event listings
- YouTube for tutorials
- Instagram for photo sharing

Our value is the **curation and the community notice board feel** — not rebuilding what exists.

## Highest-Value Build Order Within Phase 1

1. **Landing page** — Warm, inviting, explains what this is in <30 seconds
2. **Community Board** — Post creations, ask questions (localStorage)
3. **Group Directory** — Curated list of knitting/crochet groups (seeded with real data, filterable)
4. **Resource Hub** — Curated links to pattern sources, YouTube channels, helpful sites

## Seed Content Strategy

An empty board is useless. We'll seed:
- 3-5 example posts on the community board (from "Fariha" and fictional members)
- 10-15 real knitting/crochet groups in the directory (mix of online and UK-based in-person)
- 8-10 curated resource links (Ravelry, YouTube channels, free pattern sites)
