- **Mobile hamburger nav** — responsive menu for screens < 768px
- **Post reactions** — ❤️ 👏 🧶 ⭐ with visible labels, generous touch targets, toggle and counts
- **Gallery view** — Grid layout with obvious text-labeled toggle ("List" / "Gallery")
- **Feedback widget** — Two-step: emoji quick → optional text. Floating, non-intrusive.
- **Save for later** — Pin posts with 📌, view them on My Saved page
- **Image error handling** — Graceful fallback when images fail to load
- **Accessible by Default** — Added as Constitutional Principle #7

## Known Gaps

- No automated tests
- No user accounts or cross-device sync (localStorage only)
- Reactions are per-browser (not shared between users)
- Feedback stored locally — no aggregation dashboard
- Group directory is static (not user-editable)
- No image upload (paste URL only)
- No post edit/delete functionality
- No marketplace/selling features yet (Phase 3)
- Existing localStorage data from Phase 1 won't have reactions (handled with fallback defaults)
- Users need to clear localStorage to see updated seed data with images
