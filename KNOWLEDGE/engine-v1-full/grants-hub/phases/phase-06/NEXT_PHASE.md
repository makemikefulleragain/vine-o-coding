# Next Phase Proposal: Phase 6 — Respond to User Feedback

**Date:** 2026-02-14

---

## Why This Phase

Phase 5.5 built the feedback infrastructure and defined the outreach channels. Once real users have tried the tool and provided feedback (acceptance gate: 3+ responses), Phase 6 builds whatever they say matters most.

## Proposal

Phase 6 scope is **intentionally undefined** until Phase 5.5 feedback is collected and summarised. The scope will be determined by:

1. Analysing feedback responses from the Google Form
2. Reviewing tester signup patterns (who opted in, from which channels)
3. Identifying the top 3 themes from user feedback
4. Building the highest-value response to those themes

### Candidate Scopes (to be validated by feedback)

Based on Phase 5 NEXT_PHASE.md and Phase 5.5 research, likely candidates include:

- **Print/PDF polish** — if treasurers say they need professional-looking printed reports
- **JSON data import** — if users ask for backup/restore or multi-device without accounts
- **Onboarding tutorial** — if first-time users report confusion
- **Grant templates** — if treasurers want pre-filled categories for common funders
- **Team/sharing features** — if the #1 request is sharing access with committee members
- **Something unexpected** — real users often surface needs we haven't imagined

### Alternative: Pivot

If feedback reveals the tool fundamentally misses the mark (e.g., treasurers don't use web tools, or acquittals aren't the real pain point), Phase 6 could be a strategic pivot based on that evidence. The CONSTITUTION supports this: "Evidence Changes the Plan."

## Dependencies

- Phase 5.5 acceptance gate must be met: feedback infra deployed, 3+ channels used, 3+ responses collected
- Feedback must be summarised in `phases/phase-06/user-feedback/summary.md`

## Risks

- **Low response rate.** If outreach doesn't reach real treasurers, we'll have no signal to build on. Mitigation: multiple channels, direct peer outreach.
- **Contradictory feedback.** Different users may want different things. Mitigation: triage by frequency and constitutional alignment.
- **Scope inflation.** "Respond to feedback" can expand infinitely. Mitigation: pick top 3 themes, time-box the phase.
