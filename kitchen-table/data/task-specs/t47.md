**Tags:** build

## Goal

Waymaker already persists `chatHistory` in `localStorage` across page reloads (this works now). This task extends that into structured session capture — so key decisions, insights, and follow-ups survive across *days*, not just reloads, and can inform future Waymaker context.

---

## Done When

- [ ] "Save Session" button in Waymaker panel exports the current session as structured markdown
- [ ] Export format: `ARCHIVE/waymaker-sessions/YYYY-MM-DD-session.md`
- [ ] Structure includes: date, page context, conversation summary, key decisions, insights, follow-ups
- [ ] Rolling `ARCHIVE/waymaker-insights.md` — Mike manually updates with cross-session patterns
- [ ] Waymaker system prompt updated to accept injected session history snippet when provided
- [ ] Tested across 3+ sessions — future conversations reference past decisions rather than re-solving

---

## What Already Works (don't re-build)

`loadHistory()` and `saveHistory()` in `waymaker.js` already store up to 20 messages in `localStorage['kt-waymaker']`. Chat history survives page reloads. This is t47's foundation — don't replace it.

---

## Next Most Obvious Move

**Add the "Save Session" export button** to the Waymaker panel header.

```
In waymaker.js createChatUI() — add 💾 button to .wm-header-right
On click → call saveSessionExport():
  1. Pull chatHistory from state
  2. Build markdown: date, page, message log, prompt for key decisions/insights
  3. Offer as download: waymaker-session-YYYY-MM-DD.md
```

This is ~40 lines. No server needed — `Blob` + `URL.createObjectURL` download.
