# KAMUNITY RHYTHM
## The Cadences That Keep It Alive
### Last Updated: Feb 19, 2026

*Documents go stale. Plans drift. The only antidote is rhythm — regular, lightweight check-ins that keep the system honest. This document defines what gets checked, when, and by whom.*

*The rhythm serves the operator. If it becomes a burden, simplify it. If it's skipped twice, it's too heavy.*

---

## Weekly — Monday Morning (30 mins)

The most important cadence. If you do nothing else, do this.

### The Monday Check (Mike + Waymaker)

**1. State Update (10 mins)**
- Open STATE.md — is it still true?
- Update "Current Period" section with this week's focus
- Check: any new blockers? Any blockers resolved?
- Update financial state if anything changed (invoice sent, payment received, expense)
- Update relationship status (meeting happened? follow-up needed?)

**2. Safety Scan (5 mins)**
- Glance at SAFETY_GATES.md — any gate status changed?
- Any new incidents or near-misses to log?
- Crisis numbers still current? (monthly deep check, weekly glance)

**3. Queue Review (10 mins)**
- Open PHASE_QUEUE.md — is the priority order still right?
- What's the single most important thing this week?
- Any phase DONE that needs marking?
- Any phase BLOCKED that needs unblocking?
- Move anything from PARKING LOT to active if triggered?

**4. Ecosystem Pulse (5 mins)**
- Quick check: are the key sites still live? (kamunity.org, kamunity.ai, audit, readiness)
- Any ally follow-ups overdue?
- Anything in the news about Kamunity's sector? (WACOSS, ALIKE, digital inclusion WA)

### Output
Update STATE.md with any changes. Log any decisions in DECISION_LOG.md. Done.

## Monthly — First Monday of Month (1 hour)

### The Monthly Review (Mike + Waymaker)

**1. Numbers Check (15 mins)**
- Revenue this month vs target
- API costs
- Kai encounters (if trackable)
- Audit/readiness completions (if trackable)
- Ally outreach: how many contacted? How many responded?
- Tasks completed vs created

**2. Safety Deep Dive (15 mins)**
- Run through ALL safety gates — full status check
- Crisis number verification (quarterly, but check monthly if easy)
- Any Left Field challenge this month? (Gate G14)
- Review any incidents from the month

**3. Ecosystem Health (15 mins)**
- Full site check — every URL in ECOSYSTEM.md still live?
- Any sites need updating?
- Any new sites to add?
- llms.txt files current?
- Cross-links working?

**4. Reflection (15 mins)**
- What worked this month?
- What didn't?
- What did I learn?
- What would I do differently?
- Update DECISION_LOG.md with monthly reflection entry

### Output
- STATE.md updated with monthly numbers
- ECOSYSTEM.md updated if sites changed
- SAFETY_GATES.md updated with gate status
- DECISION_LOG.md updated with reflection
- PHASE_QUEUE.md reordered if priorities shifted

## Quarterly — Every 3 Months (2 hours)

### The Quarterly Strategic Review (Mike)

**1. Constitution Review (30 mins)**
- Read CONSTITUTION.md fresh — does it still feel right?
- Any principles to add, modify, or strengthen?
- Has anything happened that tests the constitution?
- Is the "Founder's Draft" label still appropriate, or is community governance ready?

**2. Threat Model Review (30 mins)**
- Read the full threat model — any new threats?
- Any mitigations that proved insufficient?
- Any threats that turned out to be non-issues?
- Update severity ratings based on evidence

**3. Strategic Direction (30 mins)**
- Is the mission still the mission?
- Are we serving the right people?
- Is the revenue model working?
- Are the right allies engaged?
- What's the biggest risk right now?

**4. Campfire Architecture Check (30 mins)**
- Is the folder structure working?
- Are documents being kept current?
- Is the BRAIN/ still accurate as a context pack?
- Does the AI Triad (Wayfinder/Waymaker/Cascade) still make sense?
- What would a new team member need that isn't documented?

### Output
- Master documents updated
- Strategic decisions logged
- Next quarter's priority themes defined

## Ad-Hoc Cadences

### After Every Meeting
- Log key decisions in DECISION_LOG.md
- Update ally status in Kitchen Table
- If transcript available → Waymaker processes → routes to zones
- Follow up within 24 hours (non-negotiable)

### After Every Build Session (Cascade)
- Update STATE.md "Campfire Architecture Status" section
- If phase completed → update PHASE_QUEUE.md
- If safety gate status changed → update SAFETY_GATES.md

### After Every Incident
- Immediate: follow incident response protocol (CONSTITUTION.md)
- Within 24 hours: update threat model
- Within 1 week: update SAFETY_GATES.md if gate criteria need changing

### When a New Project Starts
- Create foundation docs from ENGINE/TEMPLATES/
- Add to PHASE_QUEUE.md
- Add to ECOSYSTEM.md if it will have a public URL
- Create Kitchen Table zone if it needs task tracking

## The Minimum Viable Rhythm

If everything else is too much, do ONLY this:

**Every Monday, 15 minutes:**
1. Is STATE.md still true? Update if not.
2. What's the one thing this week? Check PHASE_QUEUE.md.
3. Are the critical safety gates still the same? Glance at SAFETY_GATES.md.

That's it. 15 minutes. The system stays alive.
