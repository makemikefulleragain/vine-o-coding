# Phase 3 Triage — Services + Trust + Findability

**Date:** 2026-02-17

---

## What's the highest-value thing to build?

Phase 3 is large (per PHASE_QUEUE.md it combines services, trust/security, and findability). Triage priority:

### Must build (this phase):
1. **About page** — trust signal #1. Who is behind this tool?
2. **Services/pricing page** — converts free users to paid clients (sustainability)
3. **Privacy policy** — constitutional requirement, trust builder
4. **FAQ** — answers common objections, SEO benefit with FAQPage schema
5. **llms.txt** — AI legibility per PHASE_QUEUE.md requirement
6. **JSON-LD structured data** — SEO foundation
7. **Open Graph meta tags** — social sharing

### Defer to Phase 4:
- Admin CMS for content management
- Social media content generation
- Blog/case studies/testimonials (need real content first)
- Podcast/video clips integration

**Rationale:** Phase 3 should make the site trustworthy, sustainable, and findable. Content creation tools (CMS, social media) need the foundation to exist first.

## Build Decision

Build 4 new pages (About, Services, Privacy, FAQ) + SEO/findability layer (llms.txt, JSON-LD, OG tags, sitemap). Keep it tight and deployable.
