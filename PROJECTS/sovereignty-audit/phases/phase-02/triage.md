# Phase 2 Triage — The Free Toolkit

**Date:** 2026-02-17

---

## What's the highest-value thing to build?

Four toolkit guides mapped to the four audit dimensions, plus a toolkit index page. Each guide is linked from the results page based on the user's score. Research identified three high-priority content pieces:

1. **AI Safety Starter Kit** (AI Readiness dimension) — 85% of nonprofits lack an AI policy. A one-page template is immediately valuable.
2. **Nonprofit Discount Directory** (Cost Transparency dimension) — Many orgs are literally overpaying because they don't know about Google for Nonprofits, TechSoup, etc.
3. **Data Ownership Checklist** (Data Ownership dimension) — Admin access audit, export capability check, tool inventory.
4. **Vendor Lock-in Assessment Guide** (Vendor Lock-in dimension) — Tool inventory template, Microsoft licensing changes context, switching considerations.

## Does something already exist we should integrate with?

Yes — and Constitution principle #2 (Triage) says we should link, not rebuild:
- **TechSoup** for software discounts → link to it, don't replicate their directory
- **Candid.org** for detailed AI policy frameworks → link for depth, provide our simpler template
- **Google for Nonprofits / Microsoft Nonprofits** → link directly to sign-up pages

**Decision:** Build practical, Priya-specific content. Link to authoritative external resources for depth. Don't rebuild what exists.

## Format Decision

Research confirms Priya wants:
- Checklists (scannable, actionable)
- Templates (immediately usable)
- One-pagers (respects 30 min/week)

**Decision:** Each toolkit guide is a single page with: context paragraph, actionable checklist, external resource links, and a "Need help?" CTA to Kamunity Consulting.

## What NOT to build in Phase 2

- Blog/CMS system — defer to Phase 3
- PDF generation — defer
- Interactive tool comparisons — defer (link to AlternativeTo instead)
- Full migration guides — too deep, this is a starting point
