# Research: sovereignty-calculator

**Searches used:** 4 of 5

## Search 1: SaaS dependency calculator / vendor lock-in assessment tools
**Finding:** No standalone web tool exists that calculates the hidden cost of SaaS dependencies for community organizations. What exists:
- **TechTarget SaaS evaluation checklist** — enterprise-focused RFP checklist. Not a calculator, not community-focused.
- **LeanIX SaaS evaluation matrix** — enterprise IT portfolio tool. Paid, complex, wrong audience entirely.
- **NE Digital vendor lock-in assessment** — blog post with assessment framework concepts but no tool.
- **Superblocks vendor lock-in strategies** — developer-focused article on avoiding lock-in in app building.

**Conclusion:** Nothing exists as a usable tool for small community orgs. The concept is novel in this context.

## Search 2: Data valuation frameworks
**Finding:** Academic and enterprise frameworks exist:
- **MIT Sloan "What's Your Data Worth?"** — framework based on Microsoft-LinkedIn deal valuation. Useful conceptual model but enterprise-scale.
- **Monda.ai data valuation primer** — covers income, market, and cost approaches. Good for methodology.
- **ODSC data valuation article** — distinguishes data value (property) from data valuation (methodology).

**Useful insight:** Data value can be estimated via: (1) revenue per user that companies report, (2) ad revenue models, (3) data broker market prices. For community orgs, the "extraction" value is roughly: number of members × data points per member × market rate for similar data.

## Search 3: Hidden costs of free SaaS for organizations
**Finding:**
- **Binadox "True Cost of Free SaaS"** — storage overages, limited support, feature gating. Good cost categories.
- **AppFlowy "How Free Tools Use Data Monetization"** — vendor lock-in, data monetization, workflow dependency. Directly relevant framework.

**Useful insight:** Three cost categories confirmed: (1) direct monetary costs (upgrades, overages), (2) time/switching costs (migration difficulty, training, admin overhead), (3) data extraction value (what the vendor gains from your usage data, content, and social graph).

## Search 4: SaaS migration/switching costs
**Finding:** Mostly enterprise cloud migration focused. No simple calculator for community orgs.
- Switching cost factors: data export difficulty, format compatibility, retraining time, workflow rebuilding, integration reconnection.

## Summary
- **No existing tool does this.** Build is warranted.
- **Three-dimension model is well-supported:** money, time/lock-in, data extraction.
- **Data values can be estimated** from public ARPU (Average Revenue Per User) figures for major SaaS platforms.
- **Migration difficulty can be scored** on a simple scale based on: data export availability, format openness, alternative availability.
