# Research: six-reactions

**Searches used:** 2 of 5

## Search 1: Alternative reaction systems beyond like/upvote
**Finding:**
- **Facebook Reactions** (2016+) — Love, Haha, Wow, Sad, Angry, Care. Expanded beyond Like to capture sentiment. These are emotional categories, not value-type categories. They tell you HOW someone feels, not WHAT kind of value a post provides.
- **Discord** — allows custom emoji reactions, no fixed taxonomy. Communities create their own reaction language. Flexible but no built-in analytics.
- **Reddit** — upvote/downvote only. Communities added flair and awards for nuance, but reactions are still binary. Reddit's system optimises for popularity, not for understanding content character.
- **LinkedIn** — Like, Celebrate, Support, Love, Insightful, Funny. Closer to value-type categories than Facebook's emotional ones. "Insightful" is similar to kamunity's "Fact."
- **No platform uses value-type reactions** (what KIND of value a post provides) as its primary reaction system.

## Search 2: Psychology of reactions and engagement
**Finding:**
- **LiveLike research** — varied reaction options increase engagement because users feel their specific response is represented. Binary like/dislike discourages nuanced feedback.
- **Oktopost** — platforms use reaction variety to gauge content quality. Posts with diverse reactions are algorithmically boosted.
- **Sentiment analysis research** — traditional positive/negative is too coarse. Multi-dimensional sentiment (joy, surprise, anger, etc.) provides richer signal. Kamunity's six categories map to content VALUE dimensions rather than emotional dimensions — this is a meaningfully different approach.

## Summary
- **No existing platform uses value-type reactions.** Facebook = emotional, LinkedIn = professional-emotional, Reddit = binary. Kamunity's Fact/Fun/Spicy/Nice/Curious/Surprising categorises the KIND of value, not the emotional response. This is genuinely novel.
- **Multi-reaction systems increase engagement** — research confirms this.
- **Aggregate reaction data** reveals "room character" — this analytics use case isn't done by any platform in the way described.
- **Build is clearly warranted.** The concept is original and the implementation is straightforward (React component with state management).
