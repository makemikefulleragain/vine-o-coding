# Research: community-survey-tool

## Search 1: "open source self-hosted survey tool for community organisations nonprofit"
### Findings:
- **LimeSurvey** — Free, open source (GPL), self-hosted. 15+ years mature. All question types, multilingual, templates, advanced logic, CSV export, results dashboards. GitHub: LimeSurvey/LimeSurvey. Used by nonprofits, academic institutions, governments.
- **Formbricks** — Open source (AGPLv3), self-hosted via Docker single-click. Link, email, in-app surveys. Template library. Good UX. Growing fast, active in 2026.
- **SurveyJS** — JavaScript library collection (MIT base). Render surveys, analytics dashboard, visual editor, PDF export. Free base, per-developer licensing for advanced.
- **OpnForm** — Open source form/survey builder. Multiple question types, conditional logic, data export. Beta but feature-rich.
