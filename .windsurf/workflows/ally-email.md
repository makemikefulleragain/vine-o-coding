# Ally Email — Draft Outreach

Drafts a contextual outreach email to a specific ally, using data from BRAIN/WHO.md and the Kitchen Table ally list.

## Steps

1. Ask the operator:
   - Which ally? (name or organisation)
   - What's the purpose? (introduction / follow-up / proposal / meeting request / thank you)
   - Any specific ask or offer?
   - Tone preference? (default: warm, professional, Australian-contextual)

2. Read context:
   - Open `BRAIN/WHO.md` — find the ally entry
   - Open `BRAIN/STATE.md` — check current relationship status
   - Open `BRAIN/CONSTITUTION.md` — ensure the email aligns with principles (especially #1 Real Users, #6 Sovereignty)
   - Check Kitchen Table data in `kitchen-table/js/data.js` for the ally's current status and next action

3. Draft the email:
   - Subject line (concise, specific, no buzzwords)
   - Body:
     - Personal opening (reference last interaction if known)
     - Purpose in 2-3 sentences
     - Specific ask or offer
     - Easy next step (meeting link, reply, specific question)
     - Warm close
   - Signature: Mike Fuller, Kamunity

4. Tone check:
   - Does it sound like Mike? (direct, warm, not corporate)
   - Is it under 200 words? (shorter = more likely to get read)
   - Does it respect the ally's time?
   - Does it avoid over-promising?

5. Present to operator:
   - Show the draft
   - Ask: "Send as-is, edit, or scrap?"
   - If approved, suggest: copy to clipboard or open mail client

6. Log the outreach:
   - Note in `PLAN/DECISION_LOG.md` if it's a significant relationship move
   - Update ally status in Kitchen Table if needed
