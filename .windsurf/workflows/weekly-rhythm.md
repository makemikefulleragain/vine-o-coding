# Weekly Rhythm — Monday Morning (30 mins)

Follow the cadence defined in `PLAN/RHYTHM.md`. This workflow walks through each step.

## Steps

1. **State Update (10 mins)**
   - Open `BRAIN/STATE.md`
   - Check every section — is it still true?
   - Update "Current Period" with this week's focus
   - Update "Session Highlight" with last week's key outcome
   - Check: any new blockers? Any resolved?
   - Update financial state if anything changed
   - Update relationship status (meeting happened? follow-up needed?)

2. **Safety Scan (5 mins)**
   - Open `BRAIN/SAFETY_GATES.md`
   - Any gate status changed since last week?
   - Any new incidents or near-misses to log?
   - Crisis numbers still current?
   - Report: "[X] gates open, [Y] blocking"

3. **Queue Review (10 mins)**
   - Open `PLAN/PHASE_QUEUE.md`
   - Is the priority order still right?
   - What's the single most important thing this week?
   - Any phase DONE that needs marking?
   - Any phase BLOCKED that needs unblocking?
   - Check PARKING LOT — anything triggered?

4. **Ecosystem Pulse (5 mins)**
   - Are the key sites still live? Quick check:
     - kamunity.org
     - kamunity.ai
     - sovereignty-audit site
     - ai-readiness site
   - Any ally follow-ups overdue? Check `BRAIN/WHO.md`
   - Anything in the news about Kamunity's sector?

5. **Wrap up:**
   - Save all changes to STATE.md
   - Log any decisions in `PLAN/DECISION_LOG.md`
   - Update RHYTHM.md health check table with today's date
// turbo
6. Commit: `git add -A && git commit -m "weekly rhythm: [date]"`
